Alpha Ross Poster

Alpha Ross Poster is a personal automation tool of Kristina (alphaross.com). It publishes her own original short videos, created for the Alpha Ross Universe project, to her own social media accounts, including TikTok (@alpha_ross).

The tool is not a public service and is used only by its owner. It connects to TikTok through Login Kit and the Content Posting API with the owner's explicit authorization.
