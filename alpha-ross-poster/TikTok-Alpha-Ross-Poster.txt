=== 3. Текст для «Explain how each product and scope works» (до 1000 символов)
Alpha Ross Poster is a personal automation tool used only by the account owner to publish her own original short videos to her own TikTok account (@alpha_ross). Login Kit: the owner signs in once via the Desktop flow and authorizes the app; we store only the refresh token. Scope user.info.basic: used to confirm which TikTok account is connected. Content Posting API (Direct Post), scope video.publish: a scheduled workflow uploads an already prepared video file with its caption to the owner's account. Videos are labeled as AI-generated content (is_aigc). The app does not read other users' data and is not offered to third parties.

=== 4. Причина отправки на проверку (до 120 символов)
Personal tool to publish my own original videos to my own TikTok account via Content Posting API.

=== 5. Демо-видео (mp4, до 50 МБ), записать БЕЗ пауз
1. Открыть https://kristina-d-lab.github.io/alpha-ross-poster/ (адрес должен совпадать с Web/Desktop URL).
2. Запустить python tiktok_auth.py: страница входа TikTok (видно Login Kit и scopes user.info.basic и video.publish), нажать Authorize.
3. Показать, что refresh token сохранён (само значение закрыть).
4. GitHub -> Actions -> Post - Alpha Ross -> Run workflow: platforms = tiktok, keep_files включить, jitter_minutes = 0.
5. Показать в логе [TikTok] [ok].
6. Открыть аккаунт TikTok и показать загруженное видео.
Название файла: alpha-ross-poster-tiktok-demo.mp4

=== 6. Секреты репозитория alphaross-poster (после sandbox)
1. Локально создай tiktok_keys.txt (CLIENT_KEY, CLIENT_SECRET из Sandbox), запусти python tiktok_auth.py.
2. GitHub Secrets: TIKTOK_CLIENT_KEY, TIKTOK_CLIENT_SECRET, TIKTOK_REFRESH_TOKEN, GH_SECRETS_PAT (fine-grained токен, только репозиторий alphaross-poster, право Secrets: Read and write).
3. Не коммить tiktok_keys.txt в репозиторий.
4. Пока нет аудита TikTok, видео видны только тебе (SELF_ONLY); это нормально.
